# 移除仅应用连接功能

## 目标

按用户要求完整移除「仅应用连接」，跨 Provider 只支持整套切换，仍允许独立管理和选择每个 Provider 自己的地址、密钥与模型偏好。

## 需求

- 移除列表入口、已应用/更新/恢复状态、确认与风险提示，以及被覆盖身份的专用锁定和自检逻辑。
- 删除应用/恢复连接的 IPC、共享数据结构、服务分支和新写入的持久化字段，保留普通切换、备份恢复、Provider 可用性测试与独立管理。
- 旧版偏好和事务备份仍可读取。不得在升级、启动或刷新时重写用户的当前地址、认证或备份，也不得沿用旧记录跨 Provider 借用地址或密钥。
- 同步「关于」、README 和现行规范；不改写历史归档和已发布产物。

## 验收标准

- [x] Provider 卡片没有连接覆盖相关入口或标记；「编辑 / 使用 / 删除」以及原有状态仍正常。
- [x] 旧版覆盖数据不阻断读取。实际 URL/认证只与当前 Provider 自身的受管条目匹配；未匹配的值作为外部值显示，不能用于可用性测试。
- [x] 读取旧偏好不改文件；下一次正常写入偏好时不再保存旧字段。普通切换仅应用目标 Provider，不替旧 Provider 恢复地址；可显式改选自身条目。
- [x] 旧覆盖操作产生的备份仍可列出和恢复，且原始快照不被改写。
- [x] 相关专项、路径安全、完整检查及活跃代码残留扫描通过。
