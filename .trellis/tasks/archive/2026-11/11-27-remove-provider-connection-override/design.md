# 技术设计：移除仅应用连接

- 页面 `ProvidersView` 只编排常规编辑、切换、删除、管理和测试；`ProviderList` 不再接收或发出连接动作，`ProviderStatus` 只反映普通 Provider 状态，地址和密钥控件只处理各自的选择/管理。删除两个连接专用对话框及样式。
- Vue typed client、Tauri 注册和 Rust 服务共同移除应用/恢复接口及相关 DTO。普通列表、自检和可用性测试只投影自身条目，不从其他 Provider 解析凭据。
- 保留 `provider-preferences.json` v4。由于旧字段可选，移除结构字段后由现有 Serde 未知字段行为忽略旧值；下次正常写入偏好即不再保留它，无需版本升级或启动写入。旧覆盖遗留的实际地址或当前认证如不匹配自身列表，视为外部值；用户可以通过正常操作重选自身条目，或普通切换到可用 Provider。保留显式备份恢复入口。
- 旧备份的操作名是字符串，解码不依赖旧事务枚举。保留已有快照字节和旧操作名，不保留新的应用/恢复事务入口。所有正常写入仍通过原有事务并使用 `toml_edit` 投影。
- 通过临时目录覆盖旧数据读取、正常管理、普通切换和备份兼容性；通过 Vue mock 覆盖入口消失和普通动作保留。需要回退代码时使用 Git 回退，用户数据按既有备份流程处理，不在升级或回退时自动修改用户配置。
