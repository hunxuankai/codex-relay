1. **发现并解析**：用临时目录的两个 `<name>.config.toml` 和共享 `config.toml` 写失败测试；覆盖确定的 `model_provider → env_key`、继承来源、损坏降级、安全边界及扫描不写文件。用支持版本的 Codex 在独立临时 Home 中校核叠加假设；不能离线确认的情况展示不确定，不访问真实供应商。
2. **凭据状态和编辑资格**：为环境来源定义最小读接口，用可控 fake 写失败测试；覆盖用户范围、Relay 进程范围、空值、不可读取、系统同名、大小写共享和允许/禁止编辑的变量。公开状态只返回安全描述与编辑基线，查询不写环境。
3. **事务保存**：先确认非文件资源的 `TransactionService` 事务契约及 Windows 原生暂存、原态保护、提交与回滚的验证办法。以 `save_profile_env_key` 专用 command/服务为公开边界测试设置和替换、无效基线、非法目标、外部冲突、可验证回滚和无法确认的状态；测试注入隔离 Windows 存储、提交故障和系统通知，实际配置解析和共享事务锁不 mock。保护默认配置、`auth.json`、Relay 密钥库、其他变量及敏感输出；不提供无事务的写入降级。
4. **用户入口**：用 typed command mock 测试子页、状态、复制安全命令、设置/更换弹窗、取消、可写性提示、失败和保存成功后刷新；覆盖无旧值回显、关闭或提交清空新值、键盘访问和窄窗口。同步「关于」和 README 的新能力及限制；默认切换继续通过原服务。
