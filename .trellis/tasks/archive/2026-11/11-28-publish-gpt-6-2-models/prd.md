# 新增 GPT-6.2 Astra 和 Sol 并发布更新

## 目标

在 Codex Relay 的 Provider「可用模型」中加入 `gpt-6.2-astra` 和 `gpt-6.2-sol`，验证后公开发布包含两者的 Windows 更新。用户已明确授权开始实施并发布。

## 需求

- 两个新模型可被选择、保存和应用；各自支持 `low`、`medium`、`high`、`xhigh`、`max`、`ultra`，默认 `low`，支持现有 Fast 开关，不接受 `none`。
- 保留现有模型、默认设置及已保存偏好。型号可选不等于每个供应商或账户均可调用；不新增真实网络探测。
- 正式版本高于当前 `v0.5.4`，沿用项目的 GitHub Draft 审计、Tauri updater 信任根及历史发布保留规则。

## 验收标准

- [x] 两个模型均出现在 Provider 状态目录；隔离集成测试验证保存、配置投影、推理强度及 Fast，并验证非法输入不改受管文件。
- [x] 本轮通过完整项目检查与不含更新私钥的普通 Windows 构建，不接触实际用户数据。
- [x] GitHub 发布工作流成功，`v0.5.5` 正式成为 Latest；已复核安装器、签名、更新清单及提交对应关系。
- [x] 主分支已同步发布候选；未执行的安装、升级及真实供应商调用已标记。任务归档、日志和最终分支同步由 Trellis 收尾及远端 SHA 核验确认。
