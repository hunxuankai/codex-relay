# CLI Profile 一键切换同供应商 Key

## 目标

在 CLI Profiles 的「设置 Key／更换 Key」弹窗里，复用主 Providers 页面为同一个供应商 ID 保存的命名 Key，不再需要手工复制明文。

## 需求

- 以 Profile 实际解析出的供应商 ID 精确匹配默认 `config.toml` 里的供应商，不依赖当前激活的供应商，不按显示名称猜测。
- 显示该供应商可用的命名 Key；点击某个名称即将对应值保存到当前 Profile 的专用 Windows 用户环境变量。
- 无匹配项或密钥库暂不可读时保留手动设置入口；不可写变量仍为只读。
- 保存前展示目标 Profile、主机与变量。仅点击时写入，不自动跟随 Providers 后续选择或轮换；不显示明文、不触发网络请求，不修改其他 Profile、默认配置、认证文件或密钥库。

## 验收标准

- [x] 同 ID 的非激活供应商可以选择任一可用命名 Key；同名但不同 ID、无默认供应商条目或其他供应商的 Key 不可选。
- [x] 一个按钮只提交目标和 Key 条目 ID，安全写入并回读目标变量后刷新状态；同一提交期间防止重复点击，提示刷新终端，不宣称进程热更新。
- [x] 密钥删除、改名或替换、路由变化、编辑令牌失效等情况不误写；失效时提示刷新后重试。
- [x] 缺失或不可用的来源不阻止原有手填方式；共享及其他受限变量保护不变。
- [x] 在隔离环境验证真实 Rust 服务、假的用户环境存储和模拟 IPC 的 Vue 交互，运行路径安全、Provider 回归及完整检查。
