# 在 CLI Profiles 显示当前环境变量匹配的密钥名称

## 目标

在 CLI Profiles 列表中看出每个 Profile 的 Windows 用户环境变量对应哪把已保存的命名 Key，无需打开密钥管理器或手工比对明文。

## 需求

- 以 Profile 实际解析出的 `env_key` 所指向的 Windows 用户变量为准，仅与 Providers 页面同供应商 ID 的已保存 Key 精确匹配，不使用 Providers 当前选择作为推断依据。
- 已设置的用户变量能匹配时展示 Key 名称；否则明确提示未能匹配。变量未设置、不可检测或只在 Relay 进程可见时，不推断名称，保留现有状态提示。
- 进入页面、手动刷新及保存 Key 后重新读取。只读识别适用于能读取的用户变量，不放宽对共享、系统同名及其他受限制变量的写入限制。
- 列表的匹配字段只返回名称，不回显明文、指纹或条目 ID；不读取终端环境、系统变量值或 `auth.json`，不修改配置、密钥库或环境变量。

## 验收标准

- [x] Windows 用户变量指向非当前选中的同供应商已保存 Key 时，`list_cli_profiles` 仅返回实际对应的名称。
- [x] 其他供应商、非精确相同的值、没有匹配来源的 Profile、只有进程值及缺失或损坏的密钥库均不误报名称；列表查询不创建或修复密钥库。
- [x] 页面显示匹配名称或明确的未匹配提示；点击刷新及一键切换成功后按后端回读结果更新，原有编辑限制不变。
