# 为应用内网络请求添加代理设置

## 目标

允许用户在应用设置中配置无认证 HTTP/HTTPS 代理。启用后，Codex Relay 自身发起的网络请求通过该代理，包括检查 GitHub 更新清单和下载安装包；同时提供代理测试和常见本机代理发现能力。

## 已确认事实

- 当前应用自身唯一的出站 HTTP 链路是 Tauri updater；Provider 管理只读写本地 Codex 配置，不会由 Codex Relay 代发模型请求。
- 更新检查入口位于 `src/services/tauri.ts`，当前直接调用 `@tauri-apps/plugin-updater` 的 `check()`。
- 锁定的 `tauri-plugin-updater 2.10.1` 支持 `check({ proxy, timeout })`；代理会保留在更新会话中，并同时用于检查 `latest.json` 和下载安装包。
- 更新源固定为 `https://github.com/hunxuankai/codex-relay/releases/latest/download/latest.json`。
- 应用设置保存在 Relay 应用数据目录的 `settings.json`；旧文件可通过 serde 默认字段兼容新增设置。
- MVP 不支持代理认证，因此不保存、传递或显示代理用户名和密码。

## 需求

### 手动配置

- 设置页提供代理启用开关和代理地址输入框。
- 代理地址必须是包含协议的绝对 URL，仅接受 `http://` 或 `https://`。
- 地址必须包含有效主机；包含用户名、密码、查询参数或片段的地址必须拒绝保存。
- 不接受 SOCKS、PAC、代理自动发现或省略协议的 `host:port`。
- 手动填写、修改、启用或禁用代理通过页面底部“保存设置”提交。
- 未启用代理时保持当前网络行为；启用后，下一次新发起的更新检查和下载使用该代理，已开始的更新会话不被中途切换。
- 旧版 `settings.json` 缺少代理字段时默认关闭代理。

### 测试代理

- 设置页提供“测试代理”按钮，对当前填写的代理执行真实网络请求验证。
- 测试必须通过该代理请求并解析项目现有 GitHub `latest.json`，不能只检查 TCP 端口开放。
- 单次测试超时为 5 秒。
- 成功时明确提示代理可用于访问更新源；端口不可达、代理拒绝、无效响应或超时时显示稳定、脱敏的失败信息。
- 测试操作不保存或启用代理。

### 一键设置本机代理

- 代理地址为空时显示“一键设置本机代理”按钮。
- 点击后先弹窗说明：仅检测 `127.0.0.1` 固定端口、会产生少量访问 GitHub 更新源的网络请求、确认前不会检测或修改设置。
- 用户取消确认时不得发起探测请求。
- 固定候选地址为：
  - `http://127.0.0.1:7890`
  - `http://127.0.0.1:7897`
  - `http://127.0.0.1:10809`
  - `http://127.0.0.1:1080`
  - `http://127.0.0.1:8080`
  - `http://127.0.0.1:3128`
- 所有候选并行检测，每个候选超时 5 秒；只有能够通过 updater 成功请求并解析 `latest.json` 的地址才算可用。
- 没有可用候选时弹窗提示且不修改设置。
- 一个或多个候选可用时，结果弹窗列出全部可用地址，由用户选择，不自动采用第一个结果。
- 用户点击“一键填入并启用”后立即持久化所选地址并启用代理，无需再次点击“保存设置”；保存失败时保留原设置并显示安全错误。

## 验收标准

- [ ] 设置页可以启用、禁用并保存合法代理地址，刷新或重启后状态一致。
- [ ] 非 HTTP(S)、省略协议、缺少主机、含认证信息、查询参数或片段的代理地址不会写入设置。
- [ ] 未配置或关闭代理时，更新检查行为与当前版本一致。
- [ ] 启用有效代理后，`latest.json` 检查和安装包下载都使用同一代理。
- [ ] “测试代理”成功和失败均有明确、安全的用户反馈，且不修改设置。
- [ ] 本机检测确认弹窗取消后不发起请求；确认后只检测固定的六个 `127.0.0.1` 地址。
- [ ] 六个候选并行检测且各自超时 5 秒；多个成功结果全部列出并可由键盘选择。
- [ ] 选择结果并确认后立即保存和启用；失败时原设置不变。
- [ ] 旧设置文件无需迁移脚本即可加载，代理默认为关闭。
- [ ] 自动化测试覆盖设置兼容、输入校验、事务失败、前端交互、候选并发聚合和 updater 代理参数传递。
- [ ] 测试只使用安全临时目录和 mock updater，不访问真实用户数据或真实网络。

## 范围外事项

- 不修改 Codex CLI 或模型 Provider 自身的网络代理设置。
- 不支持带用户名或密码的认证代理。
- 不支持 SOCKS、PAC、系统代理自动发现、按域名分流或省略协议的地址格式。
- 不关闭 TLS 证书或主机名校验。
- 不在启动、窗口挂载或后台定时器中自动访问网络。
